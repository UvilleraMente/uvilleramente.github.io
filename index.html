Featured tools

Two sibling tools with the same rules: everything runs in your browser, nothing is uploaded, and every change is explained.

Live

JSON Surgeon

Paste broken JSON and get valid JSON back, with an explanation for every fix.

  • Repairs LLM output: Markdown fences, chatter, truncated responses, Python and JavaScript literals.
  • Every fix is reported with its line and column in your original input.
  • Generates TypeScript interfaces, C# records, Dart classes and JSON Schema.
  • Zero-dependency npm library and CLI that share the same engine.
  • Angular 20
  • TypeScript
  • Signals
  • Web Workers
  • Vitest
  • esbuild

In development

Cipher Surgeon

Decode, verify and sign JWTs in your browser, with every claim explained and every security issue flagged.

  • JWT decoder, verifier and signer that flags alg none, expired tokens and weak HMAC secrets.
  • AES-256-GCM password-based encryption and decryption, plus hashes and HMAC.
  • “Peel the layers”: automatically unwraps base64, base64url, hex, URL encoding, JWT and JSON.
  • Zero dependencies, built on Web Crypto. Also an npm library and CLI.
  • Web Crypto
  • TypeScript
  • JWT
  • AES-GCM
  • Zero deps

Jobot

Private / local tool

A personal job-search assistant that runs entirely on my PC. It collects remote software jobs from public boards, filters them, scores them with a local LLM through Ollama, and drafts a cover letter for each good match.

  • Local AI (Ollama + Qwen3): free, and nothing leaves the machine.
  • Pre-fills application forms, but a human always reviews and presses Submit.
  • Never automates LinkedIn; a small Flask panel tracks applications and interviews.
  • Python
  • Ollama
  • Flask
  • SQLite
  • Playwright

04

About

I'm a developer from the Dominican Republic, working across C#/.NET, Angular and Flutter. The same small jobs kept coming up in that work: JSON that almost parses, and typing the matching model by hand in three languages.

Most repair tools fix things silently. I wanted tools that show what they changed and why, because a silent fix can hide a real bug, like a truncated payload. That idea became JSON Surgeon, and now Cipher Surgeon. Alongside them I build small products, like Firmalisto, aimed at one specific problem.

  • explain()Every change is reported, never silent.
  • local()Runs in the browser; your data stays with you.
  • deps = 0Zero runtime dependencies where it counts.
  • test()A framework-free, tested core with a thin UI on top.
